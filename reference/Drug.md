# `Drug` data

The data is for the comparison of the effectiveness of three analgesic
drugs to a standard drug, morphine (Finney, Probit analysis, 3rd Edition
1971, p.103). 14 groups of mice were tested for response to the drugs at
a range of doses.

## Usage

``` r
data(Drug)
```

## Format

`Drug` is a 14 row data frame with the following columns

- Drug:

  type of drug.

- Dose:

  dose volumn.

- N:

  total number of mice in each group.

- R:

  number responding mice in each group.

- log10Dose:

  log10 transformed dose volumn.
